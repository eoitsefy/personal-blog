### 更换角色时复用流程

1. 为新角色保存原创或已授权参考、固定画布、脚底锚点和静区蒙版；保留原素材，不覆盖历史版本。
2. 复用动作阶段和时间预算，为该角色制作完整 PNG 姿态和必要过程图，逐张记录参考、关键、修绘或插值来源。衍生图须绑定父帧范围及索引，修绘还要保存真实编辑来源摘要；缺省来源标为未知，不计作独立绘制。
3. 新 manifest、来源或工具代码变化后重新准备并绑定摘要。独立关键图许可只允许生成或排列过程帧；按实际全部 PNG 做技术检查、正常/半速预览和最终全帧美术许可，旧角色审批不能复用。
4. 门禁通过后运行 `scripts/publish-reviewed-wave.mjs <manifest>` 导出版本化图集，再接入播放器和回归测试。当前挥手导出器锁定 768px 原画布、19 准备图、37 槽和固定裁剪；换比例、画布或其他动作须先适配并测试导出契约，不能任意单图自动换肤。
5. 保留部署与回滚作为后续单独步骤，完成 CI、实际生产原字节和浏览器验收才更新生产状态。详细本机命令见 `14_ANIMATION_WORKBENCH.md`。
