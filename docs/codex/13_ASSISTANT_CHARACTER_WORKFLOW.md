# 助手形象创建和更换流程

本文记录博客助手的素材、动作播放和更换步骤。形象与文本问答服务独立：更换角色不需要修改数据库、供应商密钥、检索、预算或提问接口。当前版本使用有限姿态帧，不是 Live2D、骨骼动画或语音口型同步。

## 当前素材和动作

身份参考是 `public/assistant/chibi-v1.png`：原创黑金短发、耳麦、夹克、短裤和靴子的 Q 版角色，不使用游戏角色素材。使用内置 imagegen 生成新素材，要求真正透明背景，保存 PNG 的 alpha 通道，不用背景色模拟透明。

`public/assistant/chibi-{idle,wave,nod,thinking,bow,cheer}-v4.png` 是六张真正透明的 4×3 动作图集，每个动作十二张真实姿态，共 72 帧。待机、思考、鞠躬、开心为 1254×1254；挥手和点头为 1448×1086。不能按等分网格直接播放：人物实际边界仍有偏差。播放器使用 72 个实测来源矩形，统一脚底中心与基准线，绘制在 224×224 固定画布中；每组采用固定缩放，不逐帧拉伸身体。待机双臂自然下垂，逐步闭眼并重新睁眼。`public/assistant/chibi-idle-v3.png` 是 1024×1536 静态回退。之前版本及生成原图保持不变。

| 序号 | 动作 | 时长 | 播放行为 |
| --- | --- | --- | --- |
| 1 | 待机和眨眼 | 6 秒 | 长时间保持睁眼，在末段眨眼，循环 |
| 2 | 挥手 | 1.8 秒 | 抬臂、挥手、落臂，然后回到待机 |
| 3 | 点头 | 1.5 秒 | 低头、点头、抬头，然后回到待机 |
| 4 | 思考 | 2.4 秒 | 抬手托腮、轻微歪头、放手，循环；检索时自动使用 |
| 5 | 鞠躬 | 2 秒 | 渐进前倾、低头、起身，然后回到待机 |
| 6 | 开心回应 | 1.8 秒 | 抬起前臂、笑眼、放下手臂，然后回到待机 |

每组十二张真实姿态，共 72 张，不是将旧帧重复凑数。相邻姿态增加最多 45ms 的短平滑渐变，并限制在下一节点之前结束；主体时间展示真实姿态，减少长渐变重影。固定身体锚点，不对人物整体做左右移动、平移或旋转。渐变提升过渡观感，但不生成新的解剖姿态，不等于骨骼补间或 Live2D。

## 素材创建

1. 先确定原创或已授权的角色参考。记录来源与使用范围，不默认获得商业或第三方游戏素材授权。
2. 查看参考图，明确发型、衣服、配色、比例等不可改变的特征。将动作需求与身份参考分开。
3. 使用 `docs/assistant/chibi-v4-prompts.txt` 中的完整提示词作为模板。图集必须固定网格、统一中心与脚底基准线、完整人物及留白；首帧必须双臂下垂。避免文字、网格线、额外道具和整幅图平移。
4. 通过内置 imagegen 分别生成六组透明动作图集，沿用或生成独立静态回退。检查行列数、每格是否越界、手臂姿态、人物比例、眼睛/头部过渡和 alpha。若不符合，针对问题重新生成；不能只用 CSS 平移假装人物动作。
5. 将选定 PNG 复制到仓库 `public/assistant/`，使用新的版本文件名，例如 `chibi-wave-v4.png`，保留之前版本便于回滚。生成器默认目录不是生产文件来源。
6. 同步保存最终提示词、原始尺寸、行列数、动作顺序和验收结果，不记录密钥或服务器私有数据。

## 更换形象和接入

`src/lib/assistant/character.ts` 是形象配置入口，集中记录六组图集路径、原始尺寸、固定缩放、动作索引、时长、循环和时间节点。用只读 `scripts/inspect-character-sheet.mjs` 测量真实 alpha 边界；在行分隔附近寻找透明间隙，不机械等分。`CHARACTER_POSES` 每条记录为来源左、上、右、下像素与脚底中心 X；右下坐标包含末尾像素。`CHARACTER_STAGE` 定义固定画布、中心、脚底基准线和过渡时长。更换素材后必须逐帧重新测量，不能只换图片路径或照抄旧矩形。更新这里而不是分散修改所有页面。动作名称保持 `idle`、`wave`、`nod`、`thinking`、`bow`、`cheer` 可以直接复用交互。

`src/components/assistant/chibi-assistant.tsx` 中的 `Character` 使用 Canvas 显示独立裁切和对齐的姿态。浏览器动画 API 仅提供可暂停的时间钟，恒定 opacity=1，不移动整个画布；绘制时对相邻姿态采用预乘颜色叠加，避免共同身体像素在过渡中半透明。首次页面和首次对话默认待机。按需加载待机及当前动作两组素材，不在页面打开时下载全部六组。点击角色点头，也可以点击动作按钮；非循环动作完成后恢复待机。暂停、减少动态效果、隐藏页面、短视口隐藏角色或关闭对话时取消动画及绘制循环，显示双臂下垂首帧。不支持动画 API 时保留静态首帧。卸载时释放监听器和绘制任务。更换静态回退时也要同步路径与尺寸。

组件样式在 `assistant-panel.module.css`。裁切和显示大小由实测矩形及固定缩放计算，不需要为每个新角色重复写关键帧。保留移动布局、对话滚动、键盘焦点和动作暂停控制；不要为了增大角色挤掉发送框。浏览器高度不足时隐藏装饰角色，聊天继续可用。

悬浮图集的透明左右边距不接收点击，人物区域和“聊聊”按钮仍可点击。更换角色时重新测量所有姿态的可见边界，并同步 `clip-path` 点击区域；不要让透明方框挡住下层文章缩略图。当前图集左侧保留 13%、右侧保留 10% 的可穿透区域。

## 验证和发布

运行 `npm test`、`npm run lint`、`npm run typecheck`、`npm run build`。本地数据库无配置时，用既有 `UI_PREVIEW_MODE=true` 预览，不能把预览模式带进生产。

启动本地生产预览后运行 `scripts/verify-character-frames.mjs`、`scripts/verify-chibi-assistant.mjs` 与 `scripts/verify-assistant-readability.mjs`。逐帧脚本检查浏览器实际画布像素：72 个姿态的头脚留白、完整脚底、脚中心误差不超过 2 个画布像素、固定视口和渐变过程；可用 `TEST_BASE_URL=https://eastherphil.cn` 做生产只读检查，不发送 AI 提问。另两个脚本模拟回复，验证聊天、引用、错误恢复、焦点和缩放模拟。100%/90%/80%/200% 是 CSS 视口和像素密度模拟，不能当成实体手机或浏览器工具栏验收。

按所有者 2026-10-04 指示，后续在自动检查通过后直接提交、合并和部署，不再等待人工审查确认。仍保留 Git 历史、CI、磁盘/健康检查、备份和回滚保护；“不留存审查过程”不意味着删除这些安全记录。部署前确认服务器版本、工作区清洁、镜像可回滚和持久上传目录。此切片只替换应用，不改 Nginx、环境、数据库或上传 ACL。

部署后通过真实 HTTPS 检查新素材、默认下垂、动作选择、暂停、手机对话和问候；同时回归文章图片、整卡点击及高德地图。问候走已有本地回答，无供应商 token。检查失败恢复上一应用镜像，不还原数据库覆盖新内容。验收日志留在服务器运维目录，公开文档只记录非敏感结论。

## 当前限制

动作采用十二真实姿态加短平滑渐变，不承诺专业骨骼动画或完全无细节变化。复杂手部变化可能仍看出短暂渐变；以后若需要更高质量，应使用有授权的可编辑分层模型或专业逐帧素材。语音输入、语音播报和口型同步仍是独立功能，不因更换形象自动开放麦克风。
