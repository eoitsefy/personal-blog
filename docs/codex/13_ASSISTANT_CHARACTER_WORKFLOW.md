### 复用动作更换形象

1. 取得原创或已授权的新形象，按这 16 个槽位拆分：`RIG_PARTS` 顺序和关节拓扑不变。眼睛/嘴不能带肤色底块，头部必须去掉内置眼嘴；手腕和肩肘需要预留重叠区域。
2. 用完整提示词和现有图集作结构参考生成新的版本 PNG，保留真正 alpha；不能只上传任意完整人物图就宣称可复用。
3. 用 `scripts/inspect-rig-atlas.mjs` 只读测量每个附件；其搜索区域针对 v1 布局，排布变化时先调整测量区域。尺寸不是机械等分。
4. 在 `RIG_SKINS` 添加素材路径、尺寸、16 个来源矩形；新角色保持本骨架比例时，不需要重写动作曲线。头身或四肢比例变化大时，需要新增有版本的骨架/关节配置并重新校准，不能强行压缩扭曲图片。
5. 在形象选择中接入新皮肤，再跑单元、类型、lint、构建、`verify-rig-assistant.mjs` 和聊天/原版回退检查。重点看肩肘接缝、哈欠手掌遮嘴、眼嘴位置、脚底及完整头脚。换肤必须共享相同采样关节曲线，而非复制一套动作图片。
6. 测试通过直接提交部署；应用回滚镜像和旧素材仍保留。此功能不需要数据库迁移、额外服务、付费动画软件或 AI 调用。

## 素材创建

1. 先确定原创或已授权的角色参考。记录来源与使用范围，不默认获得商业或第三方游戏素材授权。
2. 查看参考图，明确发型、衣服、配色、比例等不可改变的特征。将动作需求与身份参考分开。
3. 使用 `docs/assistant/chibi-v4-prompts.txt` 中的完整提示词作为模板；打哈欠的身份参考、12 帧顺序和完整提示词见 `docs/assistant/chibi-yawn-v4-prompt.txt`。图集必须固定网格、统一中心与脚底基准线、完整人物及留白；首帧必须双臂下垂。避免文字、网格线、额外道具和整幅图平移。
4. 通过内置 imagegen 分别生成各组透明动作图集，沿用或生成独立静态回退。检查行列数、每格是否越界、手臂姿态、人物比例、眼睛/头部过渡和 alpha。若不符合，针对问题重新生成；不能只用 CSS 平移假装人物动作。
5. 将选定 PNG 复制到仓库 `public/assistant/`，使用新的版本文件名，例如 `chibi-wave-v4.png`，保留之前版本便于回滚。生成器默认目录不是生产文件来源。
6. 同步保存最终提示词、原始尺寸、行列数、动作顺序和验收结果，不记录密钥或服务器私有数据。

## 更换形象和接入

`src/lib/assistant/character.ts` 是形象配置入口，集中记录七组图集路径、原始尺寸、固定缩放、动作索引、时长、循环和时间节点。用只读 `scripts/inspect-character-sheet.mjs` 测量真实 alpha 边界；在行分隔附近寻找透明间隙，不机械等分。`CHARACTER_POSES` 每条记录为来源左、上、右、下像素与脚底中心 X；右下坐标包含末尾像素。`CHARACTER_STAGE` 定义固定画布、中心、脚底基准线和过渡时长。更换素材后必须逐帧重新测量，不能只换图片路径或照抄旧矩形。更新这里而不是分散修改所有页面。动作名称保持 `idle`、`wave`、`nod`、`thinking`、`bow`、`cheer`、`yawn` 可以直接复用交互。

`src/components/assistant/chibi-assistant.tsx` 中的 `Character` 使用 Canvas 显示独立裁切和对齐的姿态。浏览器动画 API 仅提供可暂停的时间钟，恒定 opacity=1，不移动整个画布；绘制时对相邻姿态采用预乘颜色叠加，避免共同身体像素在过渡中半透明。首次页面和首次对话默认待机。按需加载待机及当前动作两组素材，不在页面打开时下载全部七组。点击角色点头，也可以点击动作按钮；非循环动作完成后恢复待机。暂停、减少动态效果、隐藏页面、短视口隐藏角色或关闭对话时取消动画及绘制循环，显示双臂下垂首帧。不支持动画 API 时保留静态首帧。卸载时释放监听器和绘制任务。更换静态回退时也要同步路径与尺寸。

组件样式在 `assistant-panel.module.css`。裁切和显示大小由实测矩形及固定缩放计算，不需要为每个新角色重复写关键帧。保留移动布局、对话滚动、键盘焦点和动作暂停控制；不要为了增大角色挤掉发送框。浏览器高度不足时隐藏装饰角色，聊天继续可用。

悬浮图集的透明左右边距不接收点击，人物区域和“聊聊”按钮仍可点击。更换角色时重新测量所有姿态的可见边界，并同步 `clip-path` 点击区域；不要让透明方框挡住下层文章缩略图。当前图集左侧保留 13%、右侧保留 10% 的可穿透区域。

## 当前限制

原版采用十二真实姿态加短平滑渐变；新的分层骨骼版本采用连续关节补间，但仍是轻量切纸式角色，不承诺专业网格变形或完全无接缝。以后若需要更高质量，应使用有授权的专业分层模型。语音输入、语音播报和口型同步仍是独立功能，不因更换形象自动开放麦克风。
