# 助手形象创建和更换流程

本文记录博客助手的素材、动作播放和更换步骤。形象与文本问答服务独立：更换角色不需要修改数据库、供应商密钥、检索、预算或提问接口。当前恢复原版逐帧方案；分层骨骼实现仅保留为历史开发参考，不再提供公开选择。生产状态见下文。两者均不是 Live2D 或语音口型同步。

画布在动作切换/同动作重播时保持同一 DOM 节点，载入新图时保留已绘制的原中立图，过期异步载入不能覆盖新动作。静态中立画布在同分辨率下复用。按 CSS 尺寸与 devicePixelRatio 建立像素画布，上限为逻辑画布三倍；只缓存待机及当前动作的图片，不入站加载全部动作。暂停、减少动态效果、隐藏页面、短视口和关对话仍停止绘制；源图失败回退原静态图。没有分层拼装、整图平移、麦克风请求或新增模型调用。
