最终美术审查是明暗底、边界帧全图和实际显示比例的静态限定审查；不能冒充观看运行视频。浏览器另行运行三圈正常速度与一圈半速，逐圈检查36–50全部采样、四种宽度各218个动作时点、暂停、减少动态、回退解码与实际资源摘要。浏览器尺寸模拟不替代实体手机复核。

量化结果：最大相邻眼部RGB差32.2634→28.3198，降低约12.22%；全闭暗色面积511→324，减少约36.59%。此指标受颜色与宽度共同影响，不是线宽测量；并非每一对相邻帧都减少。非眼部RGBA变化与全图alpha变化均为0。

## 复现与门禁

在项目根目录运行 `node scripts/animation/prepare-blink-refinement.mjs blink-refinement-v1`。封存文件不可被不同字节覆盖；新版必须改版本设计，不覆盖这个资源URL。使用本包已冻结049即可从仓库复现，无需本地旧草稿。

`candidate.json` 绑定父来源、68帧顺序与摘要、固定裁剪、工具版本、LF规范化代码和依赖锁文件摘要。无损WebP逐槽回读验证可见RGB/alpha；PNG输出像素由当前确定性眼部算法复验。不同Sharp/libvips编码版本未承诺产出完全相同压缩字节。
